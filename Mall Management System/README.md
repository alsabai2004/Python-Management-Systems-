# 🏢 نظام إدارة المركز التجاري (Mall Management System)

نظام إدارة مركز تجاري متكامل مكتوب بلغة Python باستخدام البرمجة الكائنية (OOP). يدير النظام المتاجر، المنتجات، المخزون، المبيعات، العملاء، الموظفين، والسجلات المالية في نظام واحد متكامل.

---

## 📋 نظرة عامة

نظام إدارة المركز التجاري هو تطبيق Python يعمل في بيئة سطر الأوامر (Console) ويوفر واجهة شاملة لإدارة المركز التجاري:

- 🏬 إدارة المتاجر (إضافة، عرض، تفاصيل).
- 📦 إدارة المنتجات والمخزون (إضافة، حذف، عرض، بحث).
- 💰 إدارة المبيعات (بيع، سجل المبيعات، إيرادات).
- 👤 إدارة العملاء (إضافة، عرض، سجل المشتريات).
- 👔 إدارة الموظفين (إضافة، عرض).
- 💳 طرق الدفع المتعددة.
- 📊 السجلات المالية والتقارير.

---

## ✨ الميزات الرئيسية

### 🏬 إدارة المتاجر
- **إضافة متجر**: إضافة متجر جديد مع معرف فريد.
- **عرض المتاجر**: عرض جميع المتاجر مع عدد المنتجات.
- **تفاصيل المتجر**: عرض المخزون وسجل المبيعات لمتجر معين.

### 📦 إدارة المنتجات والمخزون
- **إضافة منتج**: إضافة منتج جديد مع (ID، اسم، سعر، كمية).
- **عرض المخزون**: عرض جميع المنتجات في متجر معين.
- **التحقق من التكرار**: منع إضافة منتج بنفس المعرف.
- **تحديث الكمية**: تحديث الكمية تلقائياً عند البيع.

### 💰 إدارة المبيعات
- **إجراء عملية بيع**: بيع منتج مع تحديد الكمية وطريقة الدفع.
- **سجل المبيعات**: عرض تاريخ المبيعات لكل متجر.
- **الإيرادات**: حساب إجمالي الإيرادات من جميع المتاجر.
- **طرق الدفع**: دعم (نقدي، بطاقة ائتمان، بطاقة خصم، دفع جوال).

### 👤 إدارة العملاء
- **إضافة عميل**: إضافة عميل جديد مع (ID، اسم، هاتف، بريد).
- **سجل المشتريات**: تتبع مشتريات العميل من المتاجر المختلفة.
- **إجمالي المشتريات**: حساب المبلغ الإجمالي الذي أنفقه العميل.

### 👔 إدارة الموظفين
- **إضافة موظف**: إضافة موظف مع (ID، اسم، مسمى وظيفي، راتب).
- **عرض الموظفين**: عرض جميع الموظفين المسجلين.

### 📊 السجلات المالية
- **تسجيل الإيرادات**: تسجيل الإيرادات اليومية مع التاريخ.
- **عرض السجلات**: عرض جميع السجلات المالية المسجلة.
- **الإيرادات الإجمالية**: حساب إجمالي الإيرادات من جميع المتاجر.

### 2️⃣ عرض المتاجر (Show Stores)


### 3️⃣ إضافة متجر (Add Store)

إضافة متجر جديد مع معرف فريد واسم.

#### مثال:
```

تم إضافة المتجر: متجر الألعاب
```

### 4️⃣ إضافة منتج لمتجر (Add Product)

إضافة منتج جديد إلى متجر محدد مع التحقق من عدم تكرار المعرف.

#### مثال:
```

اسم المنتج: سماعة رأس
السعر: 99.99
الكمية: 15
تم إضافة المنتج: سماعة رأس (ID: 103) - $99.99 x 15
```

## 🔧 التخصيص والتطوير

### إضافة التخزين الدائم (Save/Load)

يمكنك إضافة دوال لحفظ البيانات في ملفات JSON:

```python
import json

def save_data(self):
    # حفظ المتاجر والمنتجات والمبيعات والعملاء والموظفين
    with open("mall_data.json", "w") as f:
        json.dump(self.to_dict(), f, indent=4)

def load_data(self):
    try:
        with open("mall_data.json", "r") as f:
            data = json.load(f)
            self.from_dict(data)
    except FileNotFoundError:
        pass
```

### إضافة ميزات جديدة

1. **تقارير متقدمة**: تقارير المبيعات الشهرية والسنوية.
2. **خصومات وعروض**: نظام خصومات للمنتجات والعملاء.
3. **الفواتير**: إنشاء وطباعة فواتير للعملاء.
4. **واجهة رسومية (GUI)**: استخدام Tkinter أو PyQt.
5. **إدارة المخزون**: تنبيهات عند نفاد المخزون.
6. **تقييم المنتجات**: نظام تقييم للعملاء.
