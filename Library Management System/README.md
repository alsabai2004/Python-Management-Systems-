# 📚 نظام إدارة المكتبة (Library Management System)

نظام إدارة مكتبة متكامل مكتوب بلغة Python باستخدام البرمجة الكائنية (OOP). يدعم النظام عمليات CRUD كاملة (إنشاء، قراءة، تحديث، حذف) مع البحث المتقدم وعرض الكتب مرتبة.

---

## 📋 نظرة عامة

نظام إدارة المكتبة هو تطبيق Python يعمل في بيئة سطر الأوامر (Console) ويوفر واجهة شاملة لإدارة الكتب:

- 📖 إضافة كتب جديدة مع التحقق من عدم تكرار ISBN.
- 🗑️ حذف كتب باستخدام رقم ISBN.
- 📋 عرض جميع الكتب مرتبة حسب العنوان.
- 🔍 البحث عن الكتب بالعنوان أو المؤلف أو كليهما.
- ✏️ تحديث معلومات كتاب موجود.
- 📊 عرض عدد الكتب في المكتبة.

---

## ✨ الميزات الرئيسية

### 📚 إدارة الكتب
- **إضافة كتاب**: إضافة كتاب جديد مع (العنوان، المؤلف، السنة، ISBN) مع التحقق من عدم تكرار ISBN.
- **حذف كتاب**: حذف كتاب باستخدام رقم ISBN.
- **عرض الكتب**: عرض جميع الكتب مرتبة أبجدياً حسب العنوان.
- **تحديث كتاب**: تحديث أي من معلومات الكتاب (العنوان، المؤلف، السنة) باستخدام ISBN.
- **عدد الكتب**: عرض العدد الإجمالي للكتب في المكتبة.

### 🔍 البحث المتقدم
- **بحث بالعنوان**: البحث عن الكتب التي تحتوي على كلمة معينة في العنوان.
- **بحث بالمؤلف**: البحث عن الكتب التي تحتوي على كلمة معينة في اسم المؤلف.
- **بحث بالعنوان والمؤلف**: البحث عن الكتب التي تطابق كلمتي البحث معاً.

### 🛡️ التحقق من صحة البيانات
- **التحقق من ISBN**: منع إضافة كتاب بنفس رقم ISBN الموجود.
- **التحقق من السنة**: التأكد من أن سنة النشر بين 1000 و 9999.

```

```

### 2️⃣ إضافة كتاب (Add Book)

1. إدخال عنوان الكتاب.
2. إدخال اسم المؤلف.
3. إدخال سنة النشر (يتم التحقق من الصحة).
4. إدخال رقم ISBN (يتم التحقق من عدم التكرار).

#### مثال:
```
أدخل عنوان الكتاب: Clean Code
أدخل اسم المؤلف: Robert C. Martin
أدخل سنة النشر: 2008
أدخل رقم ISBN: 9780132350884
تم إضافة الكتاب: Clean Code by Robert C. Martin, 2008 (ISBN: 9780132350884)
```

### 3️⃣ حذف كتاب (Delete Book)

1. إدخال رقم ISBN للكتاب المراد حذفه.

#### مثال:
```
أدخل رقم ISBN للكتاب الذي تريد حذفه: 9780132350884
تم حذف الكتاب: Clean Code by Robert C. Martin, 2008 (ISBN: 9780132350884)
```

### 4️⃣ عرض جميع الكتب (Display Books)

عرض جميع الكتب مرتبة أبجدياً حسب العنوان.

#### مثال:
```
=== كتب المكتبة ===
1. Clean Code by Robert C. Martin, 2008 (ISBN: 9780132350884)
2. Design Patterns by Erich Gamma, 1994 (ISBN: 9780201633610)
3. The Pragmatic Programmer by David Thomas, 1999 (ISBN: 9780201616224)
```

### 5️⃣ البحث عن كتاب (Search Books)

```
خيارات البحث:
1. البحث بالعنوان
2. البحث بالمؤلف
3. البحث بالعنوان والمؤلف
اختر خيار البحث: 1
أدخل عنوان الكتاب للبحث: Clean
=== نتائج البحث ===
1. Clean Code by Robert C. Martin, 2008 (ISBN: 9780132350884)
```

### 6️⃣ تحديث كتاب (Update Book)

1. إدخال رقم ISBN للكتاب المراد تحديثه.
2. إدخال المعلومات الجديدة (اترك الحقل فارغاً للتخطي).

#### مثال:
```
أدخل رقم ISBN للكتاب الذي تريد تحديثه: 9780132350884
اترك الحقل فارغاً إذا كنت لا تريد تغييره.
العنوان الجديد (أو اضغط Enter للتخطي): Clean Code: A Handbook of Agile Software Craftsmanship
المؤلف الجديد (أو اضغط Enter للتخطي): 
سنة النشر الجديدة (أو اضغط Enter للتخطي): 2009
تم تحديث الكتاب: Clean Code: A Handbook of Agile Software Craftsmanship by Robert C. Martin, 2009 (ISBN: 9780132350884)
```

## 🏗️ هيكل الكود

### كلاس Book

```python
class Book:
    def __init__(self, title, author, year, isbn):
        self.title = title
        self.author = author
        self.year = year
        self.isbn = isbn

    def __str__(self):
        return f"{self.title} by {self.author}, {self.year} (ISBN: {self.isbn})"
```

### كلاس Library

| الدالة | الوصف |
|--------|-------|
| `add_book(book)` | إضافة كتاب مع التحقق من عدم تكرار ISBN |
| `remove_book(isbn)` | حذف كتاب باستخدام ISBN |
| `display_books()` | عرض جميع الكتب مرتبة حسب العنوان |
| `search_books(title, author)` | البحث عن الكتب بالعنوان أو المؤلف |
| `get_book_count()` | إرجاع عدد الكتب في المكتبة |
| `get_books_by_author(author)` | إرجاع قائمة الكتب لمؤلف معين |
| `update_book(isbn, title, author, year)` | تحديث معلومات كتاب موجود |

## 🔧 التخصيص والتطوير

### إضافة التخزين الدائم (Save/Load)

يمكنك إضافة دوال لحفظ الكتب في ملف JSON:

```python
import json

def save_books(self):
    with open("books.json", "w") as f:
        json.dump([book.__dict__ for book in self.books], f)

def load_books(self):
    try:
        with open("books.json", "r") as f:
            data = json.load(f)
            self.books = [Book(**b) for b in data]
    except FileNotFoundError:
        self.books = []
```

### إضافة ميزات جديدة

1. **تصدير الكتب**: تصدير قائمة الكتب إلى ملف CSV أو PDF.
2. **إعارة الكتب**: تتبع الكتب المستعارة وتواريخ الإرجاع.
3. **تصنيف الكتب**: إضافة تصنيفات (روايات، علمية، تعليمية).
4. **تقييم الكتب**: إضافة نظام تقييم للكتب.

### تحسين البحث

يمكنك إضافة بحث متقدم يدعم:
- البحث بالعنوان والمؤلف معاً (AND logic).
- البحث بالنطاق الزمني (سنة النشر).
- البحث الجزئي أو الكامل.
