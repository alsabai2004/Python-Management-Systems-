# 💱 نظام الصرافة (Exchange Office System)

نظام إدارة عمليات الصرافة متكامل مكتوب بلغة Python باستخدام البرمجة الكائنية (OOP) مع الوراثة والتجريد (Abstraction). يدعم النظام ثلاث أنواع من الخدمات مع عمليات CRUD كاملة والتخزين في ملفات نصية.

---

## 📋 نظرة عامة

نظام الصرافة هو تطبيق Python يعمل في بيئة سطر الأوامر (Console) ويوفر واجهة شاملة لإدارة عمليات الصرافة:

- 💱 إدارة عمليات صرف العملة.
- 🌍 إدارة الحوالات الدولية.
- 🏠 إدارة الحوالات المحلية.
- 💾 تخزين البيانات في ملفات نصية.
- 🔍 البحث والتصفية المتقدمة.

---

## ✨ الميزات الرئيسية

### 💱 عمليات الصرافة
- **إضافة عملية**: إضافة عملية جديدة (صرف عملة، حوالة دولية، حوالة محلية).
- **عرض العمليات**: عرض جميع العمليات مع تفاصيلها.
- **حذف عملية**: حذف عملية موجودة.
- **تعديل عملية**: تحديث بيانات عملية موجودة (العميل، المبلغ، الرسوم).

### 🔍 البحث والتصفية
- **بحث بالعميل**: البحث عن العمليات باستخدام اسم العميل.
- **تصفية حسب النوع**: عرض العمليات حسب النوع (صرف عملة، حوالة دولية، حوالة محلية).
- **عدد العمليات**: عرض العدد الإجمالي للعمليات في النظام.

### 💾 التخزين
- **حفظ تلقائي**: يتم حفظ العمليات تلقائياً في ملف نصي.
- **تحميل تلقائي**: يتم تحميل العمليات من الملف عند بدء البرنامج.

### 1️⃣ القائمة الرئيسية

```
=============================
   نظام الصرافة

### 2️⃣ إضافة عملية (Add Service)

1. اختيار نوع الخدمة:
   - `1`: صرف عملة (Currency Exchange)
   - `2`: حوالة دولية (International Transfer)
   - `3`: حوالة محلية (Local Transfer)
2. إدخال اسم العميل.
3. إدخال المبلغ.
4. إدخال قيمة الرسوم.

#### مثال:
```
اختر نوع الخدمة:
1. صرف عملة
2. حوالة دولية
3. حوالة محلية

رقم الخدمة: 1
اسم العميل: أحمد محمد
المبلغ: 500
قيمة الرسوم: 15
تم إضافة العملية
تم حفظ البيانات بنجاح
```

### 3️⃣ عرض العمليات (Show Services)

عرض جميع العمليات مع أرقامها وتفاصيلها.

#### مثال:
```
========= العمليات =========
1. صرف عملة - العميل: أحمد محمد | المبلغ: 500.0 | الرسوم: 15.0
2. حوالة دولية - العميل: سارة محمد | المبلغ: 1200.0 | الرسوم: 25.0
3. حوالة محلية - العميل: خالد عبدالله | المبلغ: 800.0 | الرسوم: 10.0
=============================
```

### 4️⃣ حذف عملية (Delete Service)

1. عرض العمليات.
2. إدخال رقم العملية المراد حذفها.

#### مثال:
```
رقم العملية للحذف: 2
تم حذف العملية: حوالة دولية
تم حفظ البيانات بنجاح
```

### 5️⃣ تعديل عملية (Edit Service)

1. عرض العمليات.
2. إدخال رقم العملية المراد تعديلها.
3. إدخال البيانات الجديدة (اترك الحقل فارغاً للتخطي).

#### مثال:
```
رقم العملية للتعديل: 1
تعديل العملية:
العميل: أحمد محمد | المبلغ: 500.0 | الرسوم: 15.0

اسم العميل الجديد (Enter لتخطي): أحمد علي
المبلغ الجديد (Enter لتخطي): 600
الرسوم الجديدة (Enter لتخطي): 20
تم التعديل
تم حفظ البيانات بنجاح
```

### 6️⃣ البحث عن عملية (Search)

إدخال اسم العميل للبحث عن جميع عملياته.

#### مثال:
```
أدخل اسم العميل للبحث: أحمد

=== نتائج البحث عن: أحمد ===
1. العميل: أحمد علي | المبلغ: 600.0 | الرسوم: 20.0
```

### 7️⃣ عرض العمليات حسب النوع (Filter by Type)

```
اختر نوع العملية:

## 🏗️ هيكل الكود

### كلاس Service (مجرد)

```python
class Service(ABC):
    def __init__(self, customer, amount, price):
        self.__customer = customer
        self.__amount = amount
        self.__price = price

    # Getter و Setter للخصائص الخاصة
    def get_customer(self): return self.__customer
    def set_customer(self, customer): self.__customer = customer
    
    @abstractmethod
    def get_category(self): pass
    
    def display(self): ...
    def to_line(self): ...
    
    @staticmethod
    def from_line(line): ...
```

### كلاسات الوراثة

```python
class CurrencyExchange(Service):
    def get_category(self):
        return "صرف عملة"

class InternationalTransfer(Service):
    def get_category(self):
        return "حوالة دولية"

class LocalTransfer(Service):
    def get_category(self):
        return "حوالة محلية"
```

### كلاس ExchangeOffice

| الدالة | الوصف |
|--------|-------|
| `add_service(service)` | إضافة عملية جديدة |
| `show_services()` | عرض جميع العمليات |
| `delete_service(index)` | حذف عملية برقمها |
| `edit_service(index)` | تعديل عملية موجودة |
| `search_by_customer(name)` | البحث بالعميل |
| `show_services_by_type(category)` | عرض العمليات حسب النوع |
| `save_to_file()` | حفظ البيانات في الملف |
| `load_from_file()` | تحميل البيانات من الملف |
