# 🍽️ نظام إدارة مطعم (Restaurant Management System)

نظام إدارة مطعم متكامل مكتوب بلغة Python باستخدام التخزين في ملفات نصية. يدعم النظام إدارة الوجبات، المشروبات، الحلويات، والطلبات مع عمليات CRUD كاملة (إنشاء، قراءة، تحديث، حذف) وبحث متقدم.

---

## 📋 نظرة عامة

نظام إدارة المطعم هو تطبيق Python يعمل في بيئة سطر الأوامر (Console) ويوفر واجهة شاملة لإدارة المطعم:

- 🍔 إدارة الوجبات (إضافة، عرض، تعديل، حذف، بحث).
- 🥤 إدارة المشروبات (إضافة، عرض، تعديل، حذف، بحث).
- 🍰 إدارة الحلويات (إضافة، عرض، تعديل، حذف، بحث).
- 📝 إدارة الطلبات (إنشاء طلبات متعددة الأصناف، عرض، تعديل، حذف، بحث).
- 💾 حفظ البيانات تلقائياً في ملفات نصية.

---

## ✨ الميزات الرئيسية

### 🍔 إدارة الوجبات (Meals)
- **إضافة وجبة**: إضافة وجبة جديدة مع السعر.
- **عرض الوجبات**: عرض جميع الوجبات مع أرقامها وأسعارها.
- **تعديل وجبة**: تحديث اسم أو سعر وجبة موجودة.
- **حذف وجبة**: حذف وجبة من القائمة.
- **بحث عن وجبة**: البحث عن وجبات بكلمة مفتاحية.

### 🥤 إدارة المشروبات (Drinks)
- **إضافة مشروب**: إضافة مشروب جديد مع السعر.
- **عرض المشروبات**: عرض جميع المشروبات مع أرقامها وأسعارها.
- **تعديل مشروب**: تحديث اسم أو سعر مشروب موجود.
- **حذف مشروب**: حذف مشروب من القائمة.
- **بحث عن مشروب**: البحث عن مشروبات بكلمة مفتاحية.

### 🍰 إدارة الحلويات (Desserts)
- **إضافة حلوى**: إضافة حلوى جديدة مع السعر.
- **عرض الحلويات**: عرض جميع الحلويات مع أرقامها وأسعارها.
- **تعديل حلوى**: تحديث اسم أو سعر حلوى موجودة.
- **حذف حلوى**: حذف حلوى من القائمة.
- **بحث عن حلوى**: البحث عن حلويات بكلمة مفتاحية.

### 📝 إدارة الطلبات (Orders)
- **إنشاء طلب**: اختيار أصناف متعددة (وجبات، مشروبات، حلويات) لعميل معين.
- **عرض الطلبات**: عرض جميع الطلبات مع تفاصيلها.
- **تعديل طلب**: تغيير اسم العميل في طلب موجود.
- **حذف طلب**: حذف طلب بالكامل.
- **بحث عن طلب**: البحث عن طلبات باسم العميل.

#### الخيارات:
- **1**: الدخول إلى قائمة إدارة الوجبات.
- **2**: الدخول إلى قائمة إدارة المشروبات.

- **4**: الدخول إلى قائمة إدارة الطلبات.
- **5**: حفظ جميع البيانات في الملفات.
- **6**: حفظ البيانات والخروج من البرنامج.

4. كتابة `4` للإنهاء وإتمام الطلب.
